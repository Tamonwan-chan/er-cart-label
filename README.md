# ฉลากยาตู้ฉุกเฉิน ER (ER Emergency-Cart Label Printer)

พิมพ์ฉลากยาสำหรับยาที่แบ่งบรรจุไว้ในตู้ยาฉุกเฉิน ER (ใช้หลังห้องยาปิดเวลา 00:00 น.)
ฉลากไม่มี HN มีช่องว่างให้พยาบาลเขียนชื่อผู้ป่วย และเว้นวิธีใช้ (ครั้งละ / วันละ) ให้เขียนเอง
ไม่ต้องเปิด visit ใน HOSxP

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โปรแกรมพิมพ์ฉลาก |
| `cart-list.js` | รายการยาในตู้ (สำรองข้อมูล) — 34 รายการ |

## วิธีใช้

1. เปิดหน้าเว็บ (GitHub Pages) หรือดับเบิลคลิก `index.html`
2. ใส่ "เหลือในตู้" ของแต่ละยา โปรแกรมคำนวณจำนวนฉลากที่ต้องพิมพ์ (สต็อก − เหลือ) หรือใส่ "พิมพ์" เอง
3. กด **พิมพ์ฉลาก** หรือ `Ctrl+Enter`
4. "เติมเต็มทั้งตู้" = พิมพ์ฉลากเต็มสต็อกทุกรายการ

ตั้งค่าเครื่องพิมพ์ (ครั้งแรก): Xprinter XP-DT427B, กระดาษ 90 × 60 มม., ขอบกระดาษ (Margins) = None, Scale 100%

## แก้ไขรายการยาและสำรองข้อมูล

1. กด **ผู้ดูแล** → ใส่ PIN → แท็บ "รายการยา" → แก้ไข → **บันทึกรายการยา**
2. แท็บ "สำรองข้อมูล" → **ดาวน์โหลด cart-list.js**
3. ใน GitHub repo นี้: **Add file → Upload files** → ลากไฟล์ `cart-list.js` ที่ดาวน์โหลดมา → **Commit changes**

ทุกเครื่องที่เปิดหน้าเว็บจะได้รายการยาใหม่อัตโนมัติ และ GitHub เก็บประวัติทุกครั้งที่แก้

## ความเป็นส่วนตัว

โปรแกรมไม่มีช่องกรอกชื่อผู้ป่วยหรือ HN และไม่เก็บข้อมูลผู้ป่วยใดๆ
บันทึกการพิมพ์เก็บเฉพาะวันเวลา ชื่อยา และจำนวนฉลาก ไว้ในเบราว์เซอร์ของแต่ละเครื่อง
